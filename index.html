IceJarvis

Личный AI-помощник на базе Hermes Agent для работы владельца с его собственными Google-сервисами: Gmail, календарём, Google Drive, документами и таблицами.

Интеграция помогает находить и разбирать письма, работать с календарём, документами и таблицами по запросу владельца. Это не сервис для регистрации сторонних пользователей.

Подключение выполняется через Google OAuth без передачи основного пароля. Разрешения используются для запрошенных функций. Отправка писем, создание или изменение событий и файлов выполняются только после разрешения владельца.
